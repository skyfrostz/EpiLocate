# 源码来源与公共历史

公开树包括原项目中的应用、契约、研究程序和经过范围核对的新增组件。它保留项目的技术来历，不公开内部运行记录、逐例对照、存储目标、历史服务地址或模型资产。

| 项目时期 | 纳入的内容 | 可据此确定的范围 |
|---|---|---|
| 早期研究与工程原型 | 单切片冻结分类与遮挡、人工复核、展示与合成流程 | 当前源码和冻结协议可审查；本机运行还须满足相应依赖。 |
| 工程专业化与界面整合 | v2 后端、独立 Worker、会话网关及 Vue 查看器；按文件选择 Clinical Canvas 的应用和接口实现 | 代码来源可追溯。各历史版本的测试和部署结论不转移到另一版本。 |
| 研究多线推进 | 数据资格、编码器、空间定位、系统集成的部分公开源码与生成检查 | 私有训练、冻结输入、完整运行证据和原历史分支均独立保存。 |
| 11 月公开快照 | 独立根的文件快照、聚合结果、生成演示、可移植 P2 以及明确标为摘录的 ROI 代码 | 可以核查发布内容与其公开测试；整包不是所有模型、数据、私有历史和生产服务的复制品。 |

10 月的主线整合保留了其当时 Git 祖先，部分文件来自另一个经审查的快照；11 月公开树采用独立发布历史。不要跨越两种来源方式推断代码曾部署、历史已完全迁移或旧记录已从所有副本消失。旧分支和恢复标签不随公开材料推送。
