# EpiLocate 公开证据数据字典

本字典用于阅读[项目审查报告](PROJECT_REVIEW_20261103_ZH.md)。同一个数值只有在分析单位、参考域、监督方式和执行状态相同时才可比较。

| 术语 | 公开报告中的含义 | 容易混淆的边界 |
|---|---|---|
| 历史代理组／来源组 | 按历史资料或数据来源组织的分析单位，分组数以各实验记录为准。 | 不能自动视作经过跨来源去重的独立患者。同一组的多张切片不增加患者分母。 |
| 来源代理标签 | 从数据集合或检查层面继承的开发标签。 | 不等于单张切片有病灶，也不等于经过临床裁定的诊断。 |
| AUROC、AP、敏感度 | AUROC 衡量阳性样本排序高于阴性样本的能力；AP 汇总精确率与召回率；敏感度是指定判定阈值下阳性样本的检出比例。 | 分母、阈值、标签定义或数据划分不同，数字不能直接对比。 |
| 遮挡位置、评分输入、前向批次 | 遮挡位置是输入上实际扰动的空间位置；评分输入可含基线及对照；一个批次可送入多个评分输入。 | 这三个计量单位不可互换，位置数减少不能直接换算为耗时减少。 |
| M16 | 该臂实际查询的 16 像素尺度位置中的最大正响应，按实验预先规定的口径聚合。 | 不是全图峰值、病灶概率或召回率。先导臂未执行时保留 `null`。 |
| K8、Dice | K8 指每个分析单位的固定 8 个采样位置。Dice 衡量预测区域与参考区域的重叠，按该实验声明的坐标和有效域计算。 | 固定采样域外未评价。模型候选区域之间的一致性另算；用过掩膜监督的结果须注明监督来源。 |
| 缓存回放、受控技术执行、配对先导 | 回放用既有响应重演算法选择；技术执行用实际模型贯通约定链路；配对先导要求在预锁输入上按相同预算运行两臂。 | 一次真实技术执行不增加配对先导已完成臂数。先导完成也不能替代独立队列上的科学对照。 |
| `0`、`null`、未评估、未运行 | `0` 是已有有效分母时测得的零；`null` 指按约定无法给出数值；未评估指空间位置或单位不在有效评价域；未运行指没有该项执行。 | 应并列报告预定数、有效数、失败及缺失原因。未查询区域不能算作正常组织或负例。 |
| 技术冻结与验收 | 冻结固定输入规则、模型、版本或参考；验收确认一个指定版本在指定环境通过预定检查。 | 代码存在、本地测试通过、目标环境部署及医学有效性是四种不同的证据。 |
