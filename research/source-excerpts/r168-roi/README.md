## 来源与使用方式

来源为 2026-10-24 R168 ROI 最终候选 V3 的 source 目录。其 R168_ROI_SOURCE_MANIFEST_V3 清单声明 Git 基线为 `461ae680b871b1ce0e3c330d37a421f9c95c8194`。候选包含该提交之外的增量，不能用该提交复原整个候选。清单中对应 7 项的原始字节数和 SHA-256 均与这里的文件一致；摘要记录在 `SHA256SUMS`。在本目录内可用 `shasum -a 256 -c SHA256SUMS` 核对。这里的摘要只指向随附源码。

`source/` 下保留候选相对路径，用于阅读对照。摘录没有应用入口、数据库实例、密钥、账户、标注实例、影像或可加载的结果数据。

后端路由依赖原平台的数据库、病例归属、会话主体及数据库依赖注入，也依赖 `backend_v2.formal_k8.models` 的两种来源模型。API 用保存的描述符核对来源和几何。这些外围应用、来源注册及准备程序均未随本摘录发布。摘录不应复制进活动的迁移或路由目录直接启动。完整候选的浏览器、数据库及授权检查不在本次复核范围内。

2026-11-03 在隔离临时目录中用本地 Vitest 按文件名执行原 `geometry.test.ts`。实际收集并执行 2 项，1 通过，1 失败。多边形校验组通过。CSS 逆变换用例中，给定视变换将第二个点映射为 (102, 102)，目标图像的宽高均为 100。原断言期望返回该越界坐标，而实现按函数注释返回 null。这里保留原实现与原断言，发布方应先确定边界契约，再调整并复测。4 个 Python 源码均通过语法解析。本次未运行后端、数据库迁移或真实图像流程。
