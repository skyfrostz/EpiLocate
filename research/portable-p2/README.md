# P2 分层遮挡查询路由

本目录从 EpiLocate 冻结的 P2 开发实现按文件导出。保留原有单父、多父路由源码，以及它调用的 224 像素网格、候选子块与正响应阈值。几何模块仅保留所需定义。示例和测试使用确定性生成的分数，运行只需要 Python 3.9 或以上的标准库。

在本目录执行：

```sh
python3 demo.py
python3 -m unittest discover -s tests -v
```

示例分别运行两臂并输出每层查询数。两臂先查 36 个 64 像素窗口，再根据响应选择 32、16 像素子块。每个细层至多查 32 个位置，其中至多 8 个用于探索。父块上限分别为 1 和 4；无正响应可提前停止。未查位置保留为未评价。

`p2.p2_routing.run(provider, arm)` 接受调用方提供的基准分数和各遮挡位置的非负响应。示例实现了所需的 provider 接口。真实模型、影像加载与控制入口不包含在这个组件中。输出反映生成函数与查询策略；它不能用来衡量定位性能。
