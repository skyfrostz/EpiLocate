# 前端工程日志

## 2026-10-01 会话隔离与异步状态修复

问题：单纯清空页面状态无法阻止已发送请求重新写回。401 与旧退出响应在微任务交错下还可能清理新登录账号。

处理：统一 session epoch、认证请求 generation、页面/病例 generation；AbortController 配合响应消费后核对；store 注册同步 reset；App 对会话版本重建私人页面。旧401在清理前核对其所属 epoch，旧logout在更新前核对请求版本。上传及新建任务绑定原病例与会话。

问题：错误 body 与任务失败原因格式不一，原始异常缺乏用户可操作含义。

处理：共用归一化与稳定码中文提示；FAILED 独立呈现；查询错误保留最近状态，推理失败不自动重跑。图片与 DICOM 各自重试，迟到的图层事件不影响最终选择。严格几何门控保持启用。

验证：72/72 单元与集成测试、TypeScript/build 通过；本地拦截合成 API 的真实浏览器验收 13 场景，实际 Cornerstone 解码/渲染和 6 组几何测量通过。不是线上或 GPU E2E。

环境：Node 24.19.0；系统 Node 20.16.0 与现锁定 jsdom 的 ESM 兼容问题通过使用已验证 runtime 解决，没有改依赖锁。原有 Cornerstone codec 外部化/包体积警告保留。
