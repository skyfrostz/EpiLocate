04 / 评测计划VALIDATION PLAN
METRICS BEFORE RESULTS

明确怎样验证，
不预设验证结论。

以下均为计划采用的指标和评价方式。本站没有发布模型性能、临床效果或任何已完成的评测结果。

计划指标已完成结果：暂无
01 / CLASSIFICATION

分类性能

AUC、准确率、敏感度、特异度

计划在公开数据集与获准的医院验证数据上分别计算。
02 / ROBUSTNESS

遮挡鲁棒性

预测一致性、置信度波动

比较不同遮挡比例和位置的分类变化。
03 / STABILITY

粗定位稳定性

跨尺度区域一致性、重复试验稳定性

观察候选区域的重叠与漂移。
04 / LOCALIZATION

精细定位

Dice、IoU、Pointing Game

以医生手工勾画为评价依据；比较粗定位与 LIME 精细化。
05 / CLINICAL

解释一致性

临床逻辑一致性评分

计划通过医生盲评、问卷或访谈评价。
06 / USABILITY

交互可用性

修正完成率、耗时、主观可用性

计划记录医生试用过程和反馈。
07 / ENGINEERING

工程性能

单例推理耗时、模块响应时间、系统体积

待真实算法接入后在本地部署环境实测。
HOSPITAL VALIDATION / CONDITIONAL

医院验证有明确前提

合作医院脱敏影像的外部验证，仅在取得授权、通过伦理审批并实际获得数据后开展。医生标注只用于定位评价，不参与弱监督训练。本站目前不接收真实影像。
